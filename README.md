# ColorShapeContingencyBehavior

This repository contains data and code needed to complete the analyses and generate the figures in the manuscript "Macaque monkeys have more difficulty learning color than shape, like children".

## File descriptions

- `figures_guide.md`: a guide for generating all main and supplementary figures in the paper using the data and code in this repository

- analysis
    - learning: analysis scripts for the short-term memory and long-term memory learning behavior 
        - `learning_performance.py`: computes accuracies and confidence intervals for initial performance or plateau performance for different trial types for tasks of interest
        - `bin_compute_confidence.py`: computes binned trial accuracies and confidence intervals for 2AFC and 4AFC short-term and 4AFC long-term memory tasks
        - `analysisRL.m`: fits Rescorla-wagner reinforcemenet learning models to the 4AFC long-term memory trial data
        - `plot_learning_curves.py`: plots binned trial data, confidence intervals, year labels, and RL fits (if applicable) (Fig. 2)
    - identification: analysis scripts for the color-shape stimuli identification trial behavior
        - `MT1P3_analysis.m`: computes probability of choosing color over shape in identification trials for both monkeys and humans; plots results (Figs. 3 and 4)
        - `getMT1P3HumanData.m`: called by `MT1P3_analysis.m`, parses human data csvs
        - `MoreColor.m`: computes and plots probability each color was rated as more colorful than other colors in human colorfulness rating task (Fig. 3)
        - `plotProbvsMoreColor.m`: computes pearson correlation between probability of choosing color in identification trials and colorfulness ratings for the 12 colored shape colors; plots prob. choosing color vs. colorfulness rating, for both humans and monkeys (Fig. 3)
        - ...: other miscellaneous functions called by the above scripts
    - color_categories: analysis scripts for the color categories behavior
        - `estimate_choice_bias.py`: for each subject, bootstraps trials, and on each bootstrap generates choice probability distributions for each cue (probability of picking each choice given cue color x), fits Gaussian distribution to choice probability distribution, and estimates choice bias from this fit
        - `analyze_choice_bias.py`: plots choice bias curve with confidence interval, plots smoothed choice bias curve, identifies negative-slope zero crossings, runs fourier regression on choice bias curve, plots fourier regression fit, computes relative harmonic power for each harmonic of the fourier fit, and compares relative harmonic power between trained and untrained monkeys (Fig. 6)
        - `psychometric_functions.py`: organizes trials as a function of trial difficulty (distance between cue and closest foil), computes accuracy in each difficulty bin, fits Weibull cdfs to these curves to estimate the psychometric functions, and computes the slope of the psychometric function halfway between floor and ceiling performance 
        - `psychometric_slopes.py`: plots the slopes of the psychometric functions for trained vs. untrained monkeys (Figs. 7, S5)
        - `TCC_model.py`: defines the free variant of the Target Confusability Competition model (see Methods details and see Garside et al., 2025)
        - `run_TCC_free.py`: fits the TCC free model on each subject's choice probability matrix with cross-validation, plots the average across folds free similarity matrix (Fig. S4)
        - `cc_functions.py`: collection of functions used in other color_categories scripts
        - `cc_plot_functions.py`: collection of plotting functions used in other color_categories scripts
